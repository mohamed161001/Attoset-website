# AttoSet — Marketing Website

This repository contains the marketing website for **AttoSet**, an AI-powered Work Operating System.

The Next.js application lives in [`attoset-web/`](./attoset-web). See [`attoset-web/CLAUDE.md`](./attoset-web/CLAUDE.md) for engineering details, and the project skill at `.claude/skills/attoset-brand/SKILL.md` for the full brand + design system.

## What AttoSet is

AttoSet is an AI-powered Work Operating System that lets organizations **build, manage, automate, and scale their operations in one unified platform**. Unlike traditional project tools that force teams into fixed workflows, AttoSet lets organizations create fully customized solutions for their unique processes — project management, CRM, operations, HR, onboarding, compliance, and any other business function.

It combines customizable databases, forms, dashboards, workflow automation, collaboration, and AI in a single platform.

**Tagline direction:** the AI-powered platform that turns ideas, processes, and operations into scalable systems — with built-in AI assistance and autonomous agents that actually execute work.

### Key features
- **Atto** — built-in AI assistant that helps users design, build, and improve workflows and systems. **Live today.**
- **Custom AI Agents** — proactive agents that execute tasks, automate processes, monitor systems, and act on behalf of teams. **Not yet shipped — coming soon.** Only Atto is live at the moment; site copy should present agents as roadmap, never as a current capability.
- Custom Workspaces · Flexible Databases · Workflow Automation · Forms & Data Collection · Dashboards & Analytics
- Multiple Views (Grid, Kanban, Calendar, Gantt) · Team Collaboration · Enterprise Security & Permissions

### Security
Enterprise-grade: role-based access control, strict permissions, audit trails, secure data handling.

## Brand

- **Personality:** modern, intelligent, bold, premium, minimalistic, enterprise-ready.
- **Colors:** Black `#000000` · White `#FFFFFF` · Primary Accent Orange `#FF512A` (`rgb(255,81,42)`).
  Orange is for key actions, highlights, CTAs, and AI/Atto interactions. Black + white form the clean UI foundation.
- **Mode:** LIGHT mode only. White background. Never a dark-mode default.

## Assets

Source assets live in [`Assets/`](./Assets): the AttoSet logo, the Atto AI assistant GIF, three design inspirations, and a screenshot of the old website. Generated accent imagery goes in `attoset-web/public/images/`.

## Working agreement

- Follow the brand colors and light-mode rule strictly.
- Use modern, consistent iconography (`lucide-react`).
- Build crisp product mockups in code; use generated imagery only for atmospheric accents.
- Keep it premium and minimal — restraint over decoration.
